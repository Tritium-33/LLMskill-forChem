# 使用指南

提供真实文件或链接，直接说想完成什么；不用先写工程化提示词。以下是使用示例，不是已经通过科学验证的效果演示。

## 从任务开始

| 任务 | 可以怎样说 | 起步技能与准备 |
| --- | --- | --- |
| 阅读论文 | “分析这篇论文。” | 给 DOI 或全文；`paper-lookup` 获取资料，`reading-contract` 阅读。已有全文可省检索 |
| 比较新意 | “和这些工作相比，新在哪里？” | 给对比材料；先做有限证据比较。完整创新性审查才考虑深审协议 |
| CIF 汇总绘图 | “检查这些 CIF，汇总晶胞参数并画图。” | 给结构文件；`pymatgen` 与绘图技能，另需相应软件 |
| VASP 输入准备 | “为这个结构准备优化输入，暂不提交。” | `dft-vasp`；结构、计算设置和合法赝势资源需明确 |
| 数据检查 | “看看这份数据有哪些问题。” | `exploratory-data-analysis` 支持的文件格式；不会因此自动开始建模 |

示例中的文件和论文由用户实际提供，助手不能自行虚构对象。缺少完成任务所必需的信息时应集中说明。数据表格/VASP 的公开合成案例不构成真实科研认证。

只安装论文阅读所需组合，例如：

```text
python tools/manage.py install --skill scientific-skill-router --skill paper-lookup --skill reading-contract
```

Windows 可用 `py -3`，Linux/WSL 可用 `python3`。`--dry-run` 可预览；安装器不自动安装科学软件。完整选项见[安装说明](install.md)。

## 同用途技能怎么选

选择区别集中维护在[技能目录](skills-catalog.md)，按目标而非来源挑选。用户明确指定时优先尊重该选择；通常一个主技能足够，另一项只有提供必要的互补能力才加入。不因为名字相似就重复执行，也不根据项目名气判断效果。

目录收录不代表已安装或环境可运行。助手选中后应读取真实 `SKILL.md` 和存在的 `PACKAGING.md`，再核对运行条件。库名称与技能名称相同，也不表示软件已经安装。

## 调用与执行记录

普通自然语言请求由宿主和模型决定是否使用技能。想明确启用 router，可以说“先用 scientific-skill-router 选择必要技能，再处理这个任务”。在支持的前端也可用 `$技能名`；不需要记住所有名称。

是否每次优先经过 router，由使用者自己选择。需要时可在宿主的个人规则中加入“化学与材料任务先读取 scientific-skill-router 选择必要技能；普通聊天和仓库维护除外”。本项目不会自动写入此规则，文件存在也不代表宿主已加载它。

| 使用方式 | 执行记录 |
| --- | --- |
| 经 router 组织组合任务 | 结果前列实际英文技能名、用途和按顺序的操作、产物与状态 |
| 经 router 选择一个技能 | 简短说明技能与用途 |
| 单项直接调用 | 保留该技能自己的规则，不强制本合集前缀 |
| 只询问建议、普通聊天或维护仓库 | 不制造执行记录 |

组合记录使用 `【本轮技能】` 和 `【执行步骤】`。失败、重试、跳过及未完成项也应列出；多技能共用一份记录。长记录可用简短前缀链接实际生成的日志，但默认记录在会话中，不自动保存文件。不展示内部思考或凭据。

只是提到某个技能不算使用，成功读取不等于完成科学验证。若模型没有读取 router 或相关规则，不能保证统一格式。面板、安装器均不监控会话。

## 组合路线怎样发挥作用

例如“检查 CIF 并画图”：模型选择结构处理技能，核对输入和软件，得到晶胞参数表，再将表格、单位和异常项交给绘图技能，最后返回表格和图。只需基础检查时可以在检查结束后直接回答，无须继续绘图或建模。

总 router 只选择和衔接。`dft-vasp` 这样的领域 router 自行选择 `static`、`relax`、`dos`、`band` 子技能；不把问题反复交回总入口。`mat-dft-vasp` 的脚本路径需要另配后端，不能与输入准备路线混用默认参数。领域说明以对应技能及打包限制为准。

组合路线补充的是数据交接，不是另一个执行平台；并发限制、硬性预算和后台任务管理由宿主提供。缺少证据或任务未完成时应直接说明，不用文件链接或未来承诺替代回答。

## 遇到找不到技能或运行失败

先确认安装环境与助手一致，尤其是 Windows 与 WSL 的目录。可运行：

```text
python tools/manage.py status --skill paper-lookup --target 实际安装目录
```

技能已在目录中但没有被宿主发现，按宿主说明重新加载或开启新会话。技能加载成功但运行失败，再检查对应软件、数据、网络或凭据；缺失依赖不代表需要重新安装整个合集。参见[兼容性](compatibility.md)及对应技能的打包说明。
