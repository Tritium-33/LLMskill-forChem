# 使用指南与通用步骤

这些技能可组合使用，不需要运行固定流水线。先说明实际任务、已有材料、希望得到的产物和资源限制；智能体应选择相关技能，并明确没有做成的步骤。

## 阅读一篇化学论文

建议从 `reading-contract` 开始：

> 请阅读这篇论文及补充材料，列出关键结论、实验或计算条件、对应页码和图表。将原文事实、你的推断和无法核实的信息分开。

1. 提供论文文件或可访问链接，确认实际打开了哪个版本。
2. 提取支持结论的证据，保留条件、单位和不确定性。
3. 对全文不可访问的部分明确标记，不能用摘要替代正文证据。
4. 如果要把论文加入参考文献，再用 `ref-check` 核对元数据。

预期产物是可回查的证据表，而非只有一段流畅摘要。

## 审查一个研究主张

以 `lit-review` 为主，必要时配合 `reading-contract` 和 `ref-check`：

> 请审查“所提出的分子描述符能在指定数据条件下改进性质预测”这一主张。找出相近工作，说明各自的数据、评价方法及与本主张的差异。记录检索式、阅读情况和未覆盖范围。

先把主张限定到具体任务和条件；随后检索关键词及同义表述，追踪近邻工作的引用链；阅读关键全文后给出逐项判断。检索预算不足时交付阶段结果和缺口，不能宣称完整性。没有发现同类工作不等于证明首次提出。

## 检查模型验证

使用 `independence-bookkeeping`：

> 请审查这份数据划分与模型评价方案。检查同一分子或高度相关样本是否跨训练与测试集、测试结果是否参与调参、比较基线是否共享可能导致相同错误的实现。

提供真实的数据划分依据、特征生成流程、调参记录及评价代码。记录数据何时参与了哪些决策；区分程序自检、独立验证和泛化评估。技能会要求证据，不能仅凭“随机划分”就认可独立性。

## 结果不理想时决定下一步

使用 `research-direction-recovery`：

> 请结合原始研究问题和现有结果，区分被证据否定的假设、方法能力不足以及缺少的输入。提出能改变决策的最小下一步，并说明何时应停止。

不要求一定找到正结果，也不自动扩展成更多计算或实验。研究方向纠偏应产出可比较的选项、证据和下一步，而不是重复换一个更宏大的题目。

## 显式与自然语言调用

Codex 可以输入 `$reading-contract`，也可以直接说“请使用原文证据核查技能”。DSH 可以用自然语言要求使用稳定英文标识，并让它报告实际加载的技能。不同前端的选择菜单、快捷键和中文显示效果可能不同。

`agents/openai.yaml` 是 OpenAI 宿主的显示元数据。中文名称方便浏览，不意味着其他宿主也必然呈现相同界面。请以实际发现的技能路径和执行记录判断是否加载，不以助手一句“已使用”作为唯一证据。

所有技能依赖宿主可用的读文件、联网和计算工具。请求文献审查不自动提供数据库权限；请求计算方案不表示已经执行计算。
