## 测试对象和方法

目标为公开论文 [10.1038/s41467-026-68735-3](https://doi.org/10.1038/s41467-026-68735-3)。七道自然语言问题分别涉及整篇分析、ML/DFT 分工、实验工况、定向检索、创新性、机理证据与主动学习概念辨析；每道题每组运行一次。

环境为 Windows、DSH `0.2.0-rc.2` headless、Node `v24.19.0`，模型 `deepseek-flash`，reasoning effort 为 `high`。实验显式配置技能目录，不能视为默认目录安装或桌面 UI 的验收。

| 组 | 实际可用配置 | 主会话成功加载次数 | 实际加载 router 的题数 |
| --- | --- | ---: | ---: |
| A | 通用 agent 工具，无项目技能目录及 skill 工具 | 0 | 0 |
| B | 具体技能，无合集 router | 6 | 0 |
| C | 与 B 相同的具体技能，加可选 router | 11 | 1/7 |

委派会话另成功加载 16 次，总计 33 次。只有 T1-C 实际加载 router 及其 DOI 路线。C 的优先规则文件与运行中的 `DSH_HOME` 不在同一位置，实际初始上下文没有该规则；不能把它解释为模型忽视了一条已正确注入的规则。

内容由一个不继承项目对话历史的 GPT-6 Astra Medium 子代理评阅：先读原论文材料、冻结量表，再看随机编号和顺序的用户输入/最终可见输出，不接收分组、成本、调用过程或旧评分。评分冻结后才关联真实组别。这里是上下文与读取范围隔离，共享底层文件系统；不是独立安全沙箱，也不是领域专家组认证。实际调用和资源由知晓组别的主代理另行审计。

## 实测后修正的判断

| 原先的不确定表述 | 本轮可以确认的内容 | 仍不能宣称的内容 |
| --- | --- | --- |

| router 路线只经过结构检查 | T1-C 实际加载 router、DOI 路线及两项具体技能 | C 组七题都经过路由，或 C/B 差异就是 router 的因果作用 |
| 技能效果没有真实问答证据 | 有局部正例和反例；T7-B 的概念辨析较好且 token 更少，T6 的 B/C 反而出现错误批评和更高消耗 | 普遍提高准确率、越多技能越好、单次分数可用于全局自动权重 |
| 深度检索开销可能较高 | T5 占全轮 73.2% token；T5-C 7 个子会话缺结束记录，且答案存在重要错误 | 高消耗意味着更全面可靠，主进程正常退出意味着全部工作完成 |

六维评分是模型评阅的序数判断，不是事实正确率。完整报告保留逐字短引、证据定位、外部核验层级及未知项，不按引用数量或批评强度判优。

## 资源与质量必须一起看

| 组 | 总 token（含委派） | 总墙钟耗时/s | 去掉 T5 后的总 token |
| --- | ---: | ---: | ---: |
| A | 14,700,192 | 1,680.5 | 7,423,422 |
| B | 40,121,875 | 3,575.2 | 14,533,089 |
| C | 77,059,739 | 2,557.1 | 13,420,781 |

全轮 96.6% token 为缓存读取；输出 token 包含推理，不等于可见回复长度。首个请求中，B 比 A 多 4,049 个逻辑输入 token，C 比 B 再多 78 个；这是初始暴露差异，不是后续整个工作流的成本。没有套用单一价格换算费用。去掉 T5 仅是敏感性展示，T5 仍属于主结果。

质量没有单一总赢家：B 在创新性和主动学习辨析中较好，C 在 ML/DFT 分工中较好，A 在定向检索和机理证据评估中较可靠；T1 的 B/C 各有缺陷，T3 的 B/C 整体相近。T5-C 消耗最高，核心判断却受到截止日错误、反向引用等问题影响。详见完整报告，不能将这些观察推广为稳定排名。

## 对项目改进的含义

优先顺序应是：核实实际指令是否注入 → 控制检索扩展并收集/终止未完成委派 → 复核图例、单位、源表标签和证据限定 → 小规模重复验证。首轮不足以支持新增自动权重系统、自动改写上游技能，或把全部问答升级成深度综述。

本次仅收录证据、修正文档判断；没有修改上游正文、公共默认规则、宿主配置或实验运行器。它不改变既有合成案例的 `not_run` 状态。继续保留自然语言使用、单项 skill 安装和轻量设施。

## 公开范围与局限

报告保留 21 份完整原始问答（含错误），它们是评估对象，不是科研参考答案。仅将报告中的一处机器专属根路径替换为 `<experiment-root>`，并添加公开收录说明；没有修改回答或评分。报告里的原始日志/中间文件路径只是审计定位，不表示这些文件随仓库发布。

没有收录私人会话日志、隐藏思考、账号配置、机器路径、论文 PDF 或原始工作簿。报告包含引用和复核定位，可通过出版来源核查科学论断；但公开包不足以独立重跑原始日志审计或核对服务端账单。哈希用于识别版本，不能单独证明结论。

每题每组只有一次运行，且七题围绕同一篇论文；外部网络、配额、缓存和生成随机性未完全受控。内容评分只有一个模型评审者。测试结束不等于科学能力认证；涉及真实研究决策，仍应复核关键证据。
