结果：五项技能的目录、基础元数据、来源固定版本和必需许可文件检查通过；13 项安装器测试通过。

覆盖：真实命令行安装/状态/卸载、中文与空格路径、预览不写入、重复安装、同名冲突、局部安装、保护无关技能、本地修改保护、备份替换、删除过时资源、安装清单写入失败后的回滚、拒绝符号链接与源码重叠目标、拒绝未知技能名和路径穿越。

## 简化技能选择器（同日更新）

原型的任务表单、指令预览和发送按钮已移除。以下结果针对简化后的版本，替代上一节有关旧界面操作的验证：

- 仅支持普通消息发送或普通上下文更新的模拟宿主：不冒充输入框附件支持，显示“复制”。
- Linux/WSL 与 Windows 原生 Python 的真实 MCP stdio：四项工具、中文原生菜单搜索、全部五项资源与原文一致、未知资源拒绝通过。

- 19 项 unittest、目录检查、插件及入口技能格式检查通过。

这些测试不证明真实 Codex 输入框或原生 `@` 菜单已经显示；需由实际宿主验证。
