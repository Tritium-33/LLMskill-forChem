# 化学科研技能面板

用户请求菜单时，调用本插件 MCP 的 `open_skill_panel`。工具只返回目录与界面，尚未开始科研任务。若当前客户端不渲染界面，提供工具返回的 `browser_panel` 本地文件链接，或用简洁中文列出可选项；不要宣称已显示或操作用户没有看到的界面。

若 MCP 工具未连接，读取插件根目录 `catalog.json`；浏览器入口是 `assets/panel.html`。这些文件相对于本 SKILL 位于 `../../`。提示用户完成插件运行环境安装，无需模型 API Key。

面板以原始英文 skill name 为名称，中文仅解释用途；每项直接显示来源，并链接到 SOURCE.json 固定版本的原始 SKILL.md。来源在构建时从各技能 SOURCE.json 生成，不手动另维护一份。搜索支持英文名、中文用途和来源。面板保留逐项插入按钮。支持 OpenAI modelContext 扩展时，选择作为可移除附件加入当前输入框，不发送消息、不启动任务；再次选择替换本面板此前的附件。否则按钮显示“复制”，由用户粘贴。不要把复制或静默上下文更新说成已经插入可见输入框。

支持桌面 Composer mentions 的宿主还可通过原生 `@` 菜单选本插件，再搜索英文名称或中文用途；`search_skill_mentions` 空查询返回全部。此入口依赖客户端支持，不保证所有 Windows Codex 版本都显示。

用户已选择技能并提供任务时，使用 `get_skill_instructions` 取得该技能原文（或读取同级对应技能目录），按需读取其引用资源，然后处理任务。只有技能选择而没有任务时，简短确认并等待任务，不自行生成科研工作。已有明确选择时不重新展示菜单。只有请求帮忙选择时才根据目录与具体目标推荐。

`prepare_skill_task` 仅为旧版调用保留，新面板不使用它。`get_skill_instructions` 返回的 `status=instructions_loaded` 只表示取得原文。界面不传文件；用户需在对话附上材料或提供可访问路径。保持用户任务范围，依宿主现有工具和权限执行。
